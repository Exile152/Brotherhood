# Brotherhood

Brotherhood is a submod for **Battle Brothers Reforged** focused on procedural
perk-tree generation, new perks, and related tactical systems.

## Status

Brotherhood is under active development. Public releases will be published as
`mod_brotherhood.zip` on the GitHub **Releases** page. The repository's
automatically generated “Source code” downloads are not the installable mod.

## Installation

1. Install the required dependencies:
   - Reforged 0.9.2 or newer
   - Modding Standards & Utilities (MSU) 1.9.0 or newer
   - Modern Hooks 0.4.10 or newer
2. Download `mod_brotherhood.zip` from the latest GitHub release.
3. Place the ZIP, without extracting it, in the Battle Brothers `data` folder.
4. Keep only one Brotherhood ZIP in that folder to avoid loading stale files
   from an older build.

## Source

The distributable source is in `mod_brotherhood_patch/`. Third-party mod
sources, decompiled game files, local development notes, generated builds, and
private tooling are intentionally excluded from this repository.
